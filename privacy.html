Kebijakan Privasi Rumah Clipper Invoice

Terakhir diperbarui: 7 Oktober 2026

Tentang aplikasi

Rumah Clipper Invoice adalah aplikasi internal milik Rumah Clipper. Aplikasi ini berupa bot Telegram yang membuat invoice PDF dan mencatatnya di Google Sheets. Aplikasi ini hanya dipakai oleh pemilik dan tim Rumah Clipper.

Data Google yang diakses

  • Aplikasi hanya meminta izin drive.file. Artinya aplikasi hanya bisa melihat dan mengubah file yang dibuat oleh aplikasi itu sendiri, yaitu folder invoice, file PDF invoice, dan spreadsheet database invoice.
  • Aplikasi tidak bisa membaca file lain di Google Drive pengguna.

Data yang disimpan

Data klien yang dimasukkan lewat Telegram (nama, alamat, nama perwakilan, email, nomor telepon, rincian pekerjaan, harga, dan jatuh tempo) disimpan di Google Drive dan Google Sheets milik Rumah Clipper, semata-mata untuk membuat dan mengelola invoice.

Berbagi data

Data tidak dijual, tidak dibagikan kepada pihak ketiga, dan tidak dipakai untuk iklan atau melatih model AI.

Menghapus data

Data bisa dihapus kapan saja dengan menghapus file di folder invoice Google Drive. Akses aplikasi bisa dicabut di https://myaccount.google.com/permissions.

Privacy Policy (English)

Rumah Clipper Invoice is an internal Telegram bot used only by Rumah Clipper. It requests only the drive.file scope, so it can access only the files it creates (an invoice folder, invoice PDFs and an invoice spreadsheet). Client data entered through Telegram is stored only in Rumah Clipper's own Google Drive to create and manage invoices. Data is never sold, shared with third parties, used for advertising, or used to train AI models. Users can delete the files at any time and revoke access at https://myaccount.google.com/permissions.
